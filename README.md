# 鞋服CMS协作平台

面向鞋服产业的 Agent 协作流程构想。AI 辅助业务工作，负责人审核后推进流程。

**在线查看：https://leo-ai-pm.github.io/apparel-cms/**

把上面的完整 HTTPS 链接复制到微信，即可分享网页入口。网页无需 GitHub 登录。

流程包括产品需求、鞋服设计、快反决策、打样预审与验证、柔性供应链、私域运营、全场景客服，并通过产品数字线程形成反馈闭环。

支持点击节点查看输入、工作、审批和输出，以及深浅主题切换、全屏、PNG / SVG 导出。手机可横屏查看整体流程。

本图为交流构想，组织方式、业务流程与预期价值尚待调研验证。

## 发布与维护

站点为独立静态 HTML，无外部脚本依赖。GitHub Pages 从 `main` 分支根目录发布；修改 `index.html` 并推送后自动更新。
