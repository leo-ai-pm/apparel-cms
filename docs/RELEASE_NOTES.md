# 2026-10-11 公开源码快照

本版汇集当前已部署的三产品。穿搭包含最新后台系列设计与公网访问适配；产品包含多反馈规则辅助研判、角色工作区及管理审批；设计包含首页一句话创作、项目画布、对话、受控生成及审核回传。普通认证机制保留，当前公开服务采用临时免登录合成演示模式。

## 本次验证

各产品文件与前后端所有者冻结清单逐项比较。公开副本中的 README 可为移植与脱敏整理；业务源码保持对应冻结版本。原脏工作区、运行库、私人照片及服务配置不做 Git 打包。发布分支采用前进更新与正常 PR 合并，不重写旧历史。

已部署版本的验收证据：六角色页面、21 并发静态请求、38 张穿搭图片加载、三后端重启后的资料/画布/会话保持及15项服务权限阴性探针。阴性探针不等于全链路真实业务批准。过去的相关类型检查及回归已经通过，本次未重复收费生成。

## 限制

- 这是有限额度的公开演示。服务与库存样本可能随维护更新，当前源码中的 Demo 价格/库存不代表真实可售商品。
- 部分历史测试依赖原项目夹具，公开快照不能承诺旧全量测试无需配置即可运行；以各产品说明为准。
- 原私库历史未完整脱敏，因此公开仓库只接收干净当前源码，不导入其历史。此前已公开的设计仓库继续独立保留。
- 评分、最终视觉及真实业务优先级仍需要人工验证。个人效果为 AI 示意，不是尺码或真实试穿承诺。

## 保留历史网页

仓库根目录 index.html 与 styling-design.html 保持原内容。新的产品导航在 portal/，包含当前三后台协作流程；历史流程中的后续产业环节不冒充本版实现。
